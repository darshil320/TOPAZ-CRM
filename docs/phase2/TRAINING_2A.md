# Phase 2A — one-page training (Sell)

Short, role-by-role. Keep it simple for the showroom team.

## Salesperson — "make and send a price"
1. **Quotations → New quote.** Search the customer by name/phone.
2. Add each item: description, qty, price. Pick from the catalog to auto-fill, or type freely. Add a discount if you gave one.
3. The **total updates live**. Save draft.
4. **Send to customer** — they get a WhatsApp link to view and approve on their phone.
5. Customer wants changes? Open the quote → **Revise** → edit the new copy → send again. The old quote stays as a record.
6. When they **approve**, open the quote → **Create order**.

## Customer — "approve on the phone"
- Taps the WhatsApp link → sees the quote → **Approve** or **Request changes**. That's it. You get notified.

## Accounts — "record money"
1. **Payments** page shows what's collected today and who owes what (0-7 / 8-30 / 30+ days).
2. Open an order → **Record payment** → amount, type (advance/stage/final), mode. Save.
3. **Outstanding** drops automatically. A receipt is generated.
4. You **cannot** take more than the balance (owner can override). Mistakes are fixed with a **refund** row (owner/admin) — payments are never edited or deleted.

## Owner/Admin — "settings + oversight"
- **Pipeline board:** drag customers across stages; red badge = stuck too long.
- **Admin:** add/edit products, set default quote terms & validity, toggle receipt-to-customer, see WhatsApp template status.
- Only owner/admin can refund or override an over-payment.

## Golden rules
- The **system always calculates the tax** — never hand-edit totals.
- A **sent** quote can't be changed — revise it instead.
- A **recorded payment** is permanent — refund to correct.
